# Dorotheum

Fiche à remplir au fur et à mesure des tests. Copier ce dossier `_template`
pour chaque nouvelle source.

## Identité
- **Source :** <nom>  ·  **URL :** <https://...>
- **Type :** marketplace / indices-historique / enchères / autre
- **Statut :** à explorer / en test / data récupérée / abandonné

## Accès
- Comment on récupère la data : API officielle / flux / scraping HTML / JSON caché
- Faut-il un compte / une clé ? Limites de requêtes (rate limit) ?
- Le site charge-t-il en JavaScript ? (si oui → playwright)

## Format de la data
- Champs disponibles (prix, marque, modèle, référence, date, état, vendeur…)
- Historique de prix disponible ? Volume ?
- Format brut : HTML / JSON / CSV

## Légal
- Conditions d'utilisation (ToS) : scraping autorisé ? restrictions ?
- Données publiques ? (règle du projet : public uniquement)

- (ce qu'on a essayé, ce qui marche, ce qui bloque)
